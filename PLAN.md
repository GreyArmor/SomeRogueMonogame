# FlatSharp Removal Plan

## Current State

| Category | Count | Details |
|----------|-------|---------|
| Package reference | 1 | `FlatSharp` 6.3.5 in `NamelessRogue.csproj` |
| Autogenerated storage classes | 58 | `AutogeneratedSerializationClasses/*.cs` |
| Custom storage classes | 22 | `CustomSerializationClasses/*.cs` |
| Main save file | 1 | `NamelessRogueSaveFile.cs` |
| Code generator | 1 | `SerializationCodeGenerator.cs` |
| Runtime consumers | 2 | `SaveManager.cs`, `Program.cs` |

**FlatSharp APIs in use:**
- `[FlatBufferTable]` / `[FlatBufferItem(N)]` attributes
- `FlatBufferSerializer.Default.Compile<T>()`
- `FlatBufferSerializer.Default.Serialize(obj, buffer)`
- `FlatBufferSerializer.Default.Parse<T>(buffer)`
- `new FlatBufferSerializer(FlatBufferDeserializationOption.Greedy)`

## Step 5: Delete `NamelessRogueSaveFile.cs`

Remove the main save file — it is the root FlatBuffer schema class that references all storage classes.

---

## Step 6: Update `SaveManager.cs`

Remove all FlatSharp-dependent code:
- Remove `using FlatSharp;`
- Remove `SaveManager.Init()` call (calls `FlatBufferSerializer.Default.Compile<T>()`)
- Remove `SaveManager.SaveGame()` method (uses `FlatBufferSerializer.Default.Serialize`)
- Remove `SaveManager.SaveMap()` method (uses `FlatBufferSerializer`)
- Remove `SaveManager.SaveWorldTemplate()` method (uses `FlatBufferSerializer`)
- Remove `SaveManager.LoadGame()` method (uses `FlatBufferSerializer.Default.Parse`)
- Remove `SaveManager.LoadWorldMap()` method (uses `FlatBufferSerializer.Default.Parse`)
- Remove `SaveManager.LoadWorldTemplate()` method (uses `FlatBufferSerializer.Default.Parse`)
- Remove `SaveManager.BuildAndSaveAlphaWorld()` method (calls `LoadWorldTemplate` / `SaveWorldTemplate`)
- Remove `GetMaxSizeForTypeAndSave()` helper (uses `FlatBufferSerializer`)
- Remove `ByteSizesStorage` property and related XML serialization logic
- Remove all `using` statements for `AutogeneratedSerializationClasses` and `CustomSerializationClasses`
- Remove references to `IStorage<>` interface if no longer used elsewhere

---

## Step 7: Update `Program.cs`

Remove `using FlatSharp;` and the `SaveManager.Init()` / `SaveManager.BuildAndSaveAlphaWorld()` calls.

---

## Step 8: Build & Verify

Run `dotnet build` to verify no remaining FlatSharp references and no compilation errors from deleted classes.

## Step 9: Clean Up Orphaned References

Remove or update callers as needed.
